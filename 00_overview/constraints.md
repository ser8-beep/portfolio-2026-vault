# Constraints & Forbidden Practices

## Technical Constraints
- No external heavy libraries (keep JS bundle < [X]kb).
- All images must be optimized (WebP/AVIF).

## Design Constraints
- Minimum contrast ratio: 4.5:1 (WCAG AA).

## Forbidden Practices
- Do not use non-semantic HTML tags (e.g., `<div>` for buttons).
- Do not hardcode hex codes; use Design Tokens.
- Do not bypass the branching strategy.
