# Design Principles: The "Sacrosanct" Guidelines

## 1. Visual Sacrosanctity
- **The Grid is Truth:** All professional work must align to an explicit or implicit grid system.
- **Controlled Glass:** Transparency/Glassmorphism must be used to imply depth and hierarchy, never for decoration alone.
- **Design-Tool UI:** Use UI patterns inspired by Figma/Linear/Raycast (monospaced accents, subtle borders).

## 2. The Hybrid Tension
- **Professional:** High-contrast, structured, accessible.
- **Personal (000):** Organic textures, "handwritten" annotations, but maintained within the same technical framework.

## 3. Communication
- **Clarity > Cleverness:** Technical case studies must follow a Problem-Solution-Metric structure.
- **Data-Backed Narrative:** Every "Data Story" must cite its origin or research methodology.
